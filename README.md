## 🚀 Acceso Directo y Ejecución

Puedes acceder a la plataforma en vivo desde cualquiera de estas alternativas:

1. **Enlace Web App (Google Apps Script):**  
   👉 **[Abrir Auditoría Médica 2026](https://script.google.com/macros/s/AKfycbzydV2LXVIQF6p7rJpVmXXKLgEOPhHBlA4fyYa5kRhPy3NYUwsVQnQ8Rz-xqINXsHoZiA/exec)**

2. **Enlace Web (GitHub Pages):**  
   👉 **[https://guidodragani75-byte.github.io/Auditoria-2026/](https://guidodragani75-byte.github.io/Auditoria-2026/)**

3. **Acceso de Escritorio en Windows:**  
   - Haz doble clic en `Auditoria_2026.bat` o `Auditoria_2026.url` en la carpeta local.

4. **Extensión de Chrome:**  
   - En Chrome, abre `chrome://extensions/`
   - Activa el **Modo de desarrollador** (arriba a la derecha).
   - Haz clic en **Cargar descomprimida** y selecciona la carpeta `extension/`.
   - Tendrás el ícono de la app en la barra del navegador para abrirla con 1 clic.
